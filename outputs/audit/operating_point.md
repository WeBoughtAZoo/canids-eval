# 固定 FPR 重定阈值分析（诊断）

`oracle@k%` = 在 **test 负样本**上重选 τ 使 FPR≤k%（**用了 test 标签，不可部署**，只作上界）。
`AUC-ROC / AUC-PR_norm` 与阈值无关，是表征质量的干净度量。
